# AviGest - Sistema Móvil de Trazabilidad y Gestión Avícola

Aplicación móvil desarrollada en **Flutter** para la gestión y seguimiento integral de ciclos productivos en granjas avícolas. Permite monitorear en tiempo real variables críticas de producción, control de lotes e inventario de insumos.

---

## 📋 Funcionalidades Principales

- **Gestión de Lotes:** Registro y seguimiento individualizado de galpones y lotes de producción.
- **Control de Pesaje & Crecimiento:** Registro periódico de pesos muestrales y generación de curvas de rendimiento.
- **Mortalidad & Sanidad:** Registro diario de bajas y cálculo automático de tasas de supervivencia.
- **Conversión Alimenticia:** Control de consumo de alimento balanceado frente a ganancia de peso (FCR).
- **Inventario de Insumos:** Auditoría de stock de alimento, medicamentos y suministros.
- **Reportes Operativos:** Resumen de indicadores clave para toma de decisiones en campo.

---

## 🛠️ Stack Tecnológico

- **Framework:** [Flutter](https://flutter.dev/) (SDK 3.x)
- **Lenguaje:** [Dart](https://dart.dev/)
- **Gestión de Estado:** Provider / State Management
- **Plataformas:** Android & iOS

## 🚀 Instalación y Ejecución

```bash
# 1. Clonar el repositorio
git clone https://github.com/Dalitoled/granja_avicola_ios.git
cd granja_avicola_ios

# 2. Instalar dependencias
flutter pub get

# 3. Ejecutar en dispositivo o emulador
flutter run
```
